# 2SC1589 – NPN silicon RF power transistor (NEC)

No original NEC datasheet was found; values are collected from secondary sources (listed at the bottom)
and the pinout was confirmed on a real part (Varioprop C6, 2026-11-25).

| | |
|---|---|
| Manufacturer | NEC (Japan) |
| Type | NPN silicon, RF power amplifier |
| Package | TO-202 (plastic body, metal tab, 3 in-line leads) |
| Marking (example) | `NEC C1589 K96` |
| Typical use | 27 MHz CB / RC transmitter output stage, class C, 12 V supply |
| Used in | Graupner/Grundig varioprop C6 SSM 27, position **T113** (output stage) |

## Pinout (confirmed)

Looking at the marked (text) side, leads pointing down:

```
   ┌───────────────┐
   │  ○  metal tab │   tab = collector
   ├───────────────┤
   │   NEC         │
   │   C1589       │
   │   K96         │
   └──┬─────┬─────┬┘
      │     │     │
      C     E     B
    left centre right
```

| Lead | Function | Confirmed by |
|---|---|---|
| left | **Collector** | continuity to the metal tab |
| centre | **Emitter** | connects to emitter resistor R120 (2.2 Ω) on the board |
| right | **Base** | connects to base resistor R119 on the board; diode test from this lead |
| tab | Collector | continuity to the left lead |

## Design notes

- **V_EBO is only 4 V.** In a class-C stage the base swings negative; overdrive or a missing antenna can push the
  B–E junction into reverse breakdown. That is how the original part in the Varioprop C6 died
  (B–E open, B–C ≈ 200 Ω leak).
- **V_CEO 18 V** is close to the peaks of a 12 V class-C stage (up to ≈ 2 × V_CC); without load the collector swing rises further.
- Always run with antenna or dummy load.

### Operating point in the Varioprop C6 (simulation, estimated model)

| Quantity | Value |
|---|---|
| Supply | 12 V via L102 |
| Mode | class C, emitter output into tapped L105, no DC bias |
| Base resistor R119 | 22 Ω on the board (schematic: 4.7 Ω) |
| Emitter resistor R120 | 2.2 Ω |
| Dissipation | ≈ 0.3 W |
| TX current (whole transmitter) | 60 mA measured (with 2N2219A replacement) |

| 2N2218A | TO-39 | as 2N2219A, lower gain (h_FE 40–120) |
| 2SC1169, 2SC822, 2SC730 | – | listed as equivalents in the Fuji-SVEA cross-reference, not checked |
| 2SC2078, 2SC2166, 2SC1969 | TO-220 | 27 MHz CB types, larger; different package and pinout |

Selection rules: NPN, V_CEO ≥ 18 V (better ≥ 30 V), V_EBO ≥ 4 V, I_C ≥ 0.5 A, P_C ≥ 1–2 W with cooling, f_T ≥ 200 MHz.
After any swap, check current and temperature, then retune L104 / L105 / L106 for maximum output.

## Estimated SPICE model

Derived from the ratings above, **not** from NEC.

```
.model Q2SC1589 NPN(IS=5e-14 BF=40 VAF=60 IKF=0.6 RB=5 RE=0.2 RC=0.5
+ CJE=60p VJE=0.7 MJE=0.4 CJC=12p VJC=0.6 MJC=0.4 TF=0.6n TR=20n
+ BVcbo=36 Vceo=18 Icrating=0.75 mfg=NEC_est)
```

TF ≈ 1 / (2π · f_T) ≈ 0.64 ns. CJE and CJC are guesses for a ≈ 1 W RF die. SPICE BJT models do not model V_EBO breakdown.
